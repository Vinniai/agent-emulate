## 5. Layout Principles

**Spacing scale:** 1px, 2px, 4px, 8px, 16px, 20px, 24px, 32px

**Base unit:** 4px grid (values are mostly multiples of 4).

**Border radii:** 8px, 16px, 77px, 3.35544e+07px

## 6. Guidelines

### Do
- Use 4px grid for all spacing
- Use `#00000000` for primary actions and CTAs
- Stick to 3 font weights: 400, 500, 600
- Use `aBCFavorit` as the primary typeface

### Don't
- Don't introduce colors outside the palette above
- Don't mix fonts beyond aBCFavorit and inter
- Don't use inline styles when the design system covers the pattern
- Don't use border-radius values outside: 8px, 16px, 77px, 3.35544e+07px
