# Design System: Stripe Login | Sign in to the Stripe Dashboard

> Extracted from [https://dashboard.stripe.com/login](https://dashboard.stripe.com/login) by brandmd

## 1. Visual Theme & Atmosphere

**Overall mood:** Dark and moody

**Density:** Moderate. The layout uses a varied spacing scale.

**Shape language:** Rounded, friendly aesthetic with generous corner radii.

**Depth:** Uses 5 shadow styles for layering and elevation.

## 2. Color Palette & Roles

- **White** (`#FFFFFF`) — Page background
- **Dark Blue** (`#675DFF`) — Accent background
- **Dark Blue** (`#1A2C44`) — Dark background / footer
- **Dark Muted Blue** (`#3C4257`) — Primary text
- **Dark Blue** (`#533AFD`) — Secondary text
- **Dark Muted Blue** (`#697386`) — Secondary text
- **Light Blue** (`#D4DEE9`) — Divider / border
- **Black** (`#000000`) — Divider / border

## 3. Typography Rules

**Primary font:** sohne-var
**Secondary font:** Segoe UI

**Fonts by role:**
- Headings: sohne-var
- Body: sohne-var

**Type scale:**
- Body / UI: 14px, 16px, 20px, 22px
- Captions / Small: 12px, 13px

**Weights in use:** 300, 400, 500, 600

**Line heights:** 20px, 16px, 24px, 0px, 36px, 12px, 28px

**Letter spacing:** -0.2px, -0.15px

## 5. Layout Principles

**Spacing scale:** 1px, 4px, 4px 8px, 8px, 10px, 12px, 16px, 24px

**Base unit:** 4px grid (values are mostly multiples of 4).

**Border radii:** 4px, 5px, 6px, 12px, 50%

## 6. Guidelines

### Do
- Use 4px grid for all spacing
- Use `#675DFF` for primary actions and CTAs
- Stick to 4 font weights: 300, 400, 500, 600
- Use `sohne-var` as the primary typeface

### Don't
- Don't introduce colors outside the palette above
- Don't mix fonts beyond sohne-var and Segoe UI
- Don't use inline styles when the design system covers the pattern
- Don't use border-radius values outside: 4px, 5px, 6px, 12px, 50%
