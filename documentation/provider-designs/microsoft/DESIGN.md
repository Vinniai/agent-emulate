## 1. Visual Theme & Atmosphere

**Overall mood:** Dark and moody

**Density:** Moderate. The layout uses a varied spacing scale.

**Depth:** Uses 1 shadow style for layering and elevation.

## 2. Color Palette & Roles

- **White** (`#FFFFFF`) — Page background
- **Dark Blue** (`#0067B8`) — Accent background
- **Black** (`#000000`) — Primary text
- **Black** (`#00000099`) — Divider / border

## 3. Typography Rules

**Primary font:** Segoe UI Webfont
**Secondary font:** Segoe UI

**Fonts by role:**
- Headings: Segoe UI Webfont
- Body: Segoe UI Webfont

**Type scale:**
- Headings: 24px
- Body / UI: 15px, 16px
- Captions / Small: 12px, 13px

**Weights in use:** 400, 600

**Line heights:** 20px, 16px, 28px, 22px

**Letter spacing:** 3px

### Buttons

### Cards

### Inputs
- Padding: 6px 10px 6px 0px

## 5. Layout Principles

**Spacing scale:** 0.227px, 2px, 4px, 6px, 8px, 12px, 16px, 44px

**Base unit:** 4px grid (values are mostly multiples of 4).

## 6. Guidelines

### Do
- Use 4px grid for all spacing
- Use `#0067B8` for primary actions and CTAs
- Stick to 2 font weights: 400, 600
- Use `Segoe UI Webfont` as the primary typeface

### Don't
- Don't introduce colors outside the palette above
- Don't mix fonts beyond Segoe UI Webfont and Segoe UI
- Don't use inline styles when the design system covers the pattern
