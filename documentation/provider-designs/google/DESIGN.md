# Design System: Sign in - Google Accounts

> Extracted from [https://accounts.google.com](https://accounts.google.com) by brandmd

## 1. Visual Theme & Atmosphere

**Overall mood:** Balanced and professional

**Density:** Moderate. The layout uses a varied spacing scale.

**Shape language:** Subtle rounding on interactive elements.

**Depth:** Flat design with minimal shadow usage.

## 2. Color Palette & Roles

- **White** (`#FFFFFF`) — Page background
- **Dark Blue** (`#1A73E8`) — Accent background
- **Black** (`#000000`) — Primary text
- **Dark gray** (`#5F6368`) — Secondary text
- **Light Muted Blue** (`#DADCE0`) — Divider / border

## 3. Typography Rules

**Primary font:** arial

**Fonts by role:**
- Headings: arial
- Body: arial

**Type scale:**
- Headings: 24px
- Body / UI: 14px, 16px
- Captions / Small: 12px

**Weights in use:** 400, 500

**Line heights:** 20.0004px, 17.1432px, 15.9996px, 31.9992px, 24px, 34px, 36px

**Letter spacing:** 0.25px, 0.15px, 0.1px

## 4. Component Stylings

### Buttons
- Background: `rgb(26, 115, 232)`
- Text color: `rgb(255, 255, 255)`
- Corner radius: 4px
- Padding: 0px 24px 0px 24px
- Font: 14px, weight 400

### Cards
- Corner radius: 0px 4px 4px 0px

### Inputs
- Border: 0px none rgb(32, 33, 36)
- Padding: 0px 14px 0px 14px
- Font size: 16px

## 5. Layout Principles

**Spacing scale:** 3px, 6px, 8px, 9px, 14px, 16px, 16.0002px, 24px

**Base unit:** 8px grid (values are mostly multiples of 8).

**Border radii:** 0px 4px 4px 0px, 4px, 4px 0px 0px 4px, 8px

## 6. Guidelines

### Do
- Use 8px grid for all spacing
- Use `#1A73E8` for primary actions and CTAs
- Stick to 2 font weights: 400, 500
- Use `arial` as the primary typeface

### Don't
- Don't introduce colors outside the palette above
- Don't mix fonts. Use arial everywhere
- Don't use inline styles when the design system covers the pattern
- Don't use border-radius values outside: 0px 4px 4px 0px, 4px, 4px 0px 0px 4px, 8px
