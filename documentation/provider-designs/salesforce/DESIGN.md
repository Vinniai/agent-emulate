# Design System: Login | Salesforce

> Extracted from [https://login.salesforce.com](https://login.salesforce.com) by brandmd

## 1. Visual Theme & Atmosphere

**Overall mood:** Balanced and professional

**Density:** Compact. The layout uses a varied spacing scale.

**Shape language:** Sharp, geometric edges.

**Depth:** Uses 1 shadow style for layering and elevation.

## 2. Color Palette & Roles

- **Light Muted Blue** (`#F4F6F9`) — Page background
- **Dark Blue** (`#0070D2`) — Accent background
- **Dark Blue** (`#03234D`) — Primary text
- **Dark Muted Blue** (`#54698D`) — Secondary text
- **White** (`#FFFFFF`) — Light text (on dark)
- **Black** (`#000000`) — Primary text
- **Light Muted Blue** (`#D8DDE6`) — Divider / border
- **Dark gray** (`#969492`) — Divider / border

## 3. Typography Rules

**Primary font:** SFS

**Fonts by role:**
- Headings: SFS
- Body: SFS

**Type scale:**
- Body / UI: 14px, 16px
- Captions / Small: 12px, 13px, 13.3333px

**Weights in use:** 400, 700

**Line heights:** 24px

## 4. Component Stylings

### Buttons
- Background: `rgb(0, 112, 210)`
- Text color: `rgb(255, 255, 255)`
- Corner radius: 4px
- Padding: 12px 24px 12px 24px
- Font: 13px, weight 400

### Cards
- Shadow: `rgb(0, 112, 210) 0px 0px 3px 0px`
- Corner radius: 4px

### Inputs
- Background: `rgb(255, 255, 255)`
- Border: 1px solid rgb(21, 137, 238)
- Corner radius: 4px
- Padding: 12px 12px 12px 12px
- Font size: 13px

## 5. Layout Principles

**Spacing scale:** 3px, 8px, 12px, 16px, 20px, 24px, 100px, 170px

**Base unit:** 8px grid (values are mostly multiples of 8).

**Border radii:** 4px

## 6. Guidelines

### Do
- Use 8px grid for all spacing
- Use `#0070D2` for primary actions and CTAs
- Stick to 2 font weights: 400, 700
- Use `SFS` as the primary typeface

### Don't
- Don't introduce colors outside the palette above
- Don't mix fonts. Use SFS everywhere
- Don't use inline styles when the design system covers the pattern
- Don't use border-radius values outside: 4px
