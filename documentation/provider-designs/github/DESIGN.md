## 1. Visual Theme & Atmosphere

**Overall mood:** Balanced and professional

**Density:** Compact. The layout uses a tight spacing scale.

**Shape language:** Rounded, friendly aesthetic with generous corner radii.

**Depth:** Uses 2 shadow styles for layering and elevation.

## 2. Color Palette & Roles

- **White** (`#FFFFFF`) — Page background
- **Dark Blue** (`#0969DA`) — Accent background
- **Dark Green** (`#1F883D`) — Accent background
- **Black** (`#000000`) — Primary text
- **Dark Muted Blue** (`#59636E`) — Secondary text
- **Light Muted Blue** (`#D1D9E0`) — Divider / border

## 3. Typography Rules

**Primary font:** Mona Sans VF

**Fonts by role:**
- Headings: Mona Sans VF
- Body: Mona Sans VF

**Type scale:**
- Body / UI: 14px, 16px, 20px
- Captions / Small: 12px

**Weights in use:** 400, 500, 600

**Line heights:** 21px, 18px, 20px, 30px

## 4. Component Stylings

### Buttons
- Text color: `rgb(9, 105, 218)`
- Corner radius: 6px
- Padding: 0px 0px 0px 0px
- Font: 14px, weight 500

### Cards
- Shadow: `rgb(9, 105, 218) 0px 0px 0px 1px inset`
- Corner radius: 6px

### Inputs
- Background: `rgb(255, 255, 255)`
- Border: 1px solid rgb(9, 105, 218)
- Corner radius: 6px
- Padding: 5px 12px 5px 12px
- Font size: 16px

## 5. Layout Principles

**Spacing scale:** 4px, 5px, 8px, 12px, 16px, 32px

**Base unit:** 4px grid (values are mostly multiples of 4).

**Border radii:** 6px, 50%

## 6. Guidelines

### Do
- Use 4px grid for all spacing
- Use `#0969DA` for primary actions and CTAs
- Stick to 3 font weights: 400, 500, 600
- Use `Mona Sans VF` as the primary typeface

### Don't
- Don't introduce colors outside the palette above
- Don't mix fonts. Use Mona Sans VF everywhere
- Don't use inline styles when the design system covers the pattern
- Don't use border-radius values outside: 6px, 50%
