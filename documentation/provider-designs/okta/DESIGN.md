## 6. Guidelines

### Do
- Use 4px grid for all spacing
- Use `#3F59E4` for primary actions and CTAs
- Stick to 2 font weights: 400, 500
- Use `Aeonik` as the primary typeface

### Don't
- Don't introduce colors outside the palette above
- Don't mix fonts beyond Aeonik and Season Mix
- Don't use inline styles when the design system covers the pattern
- Don't use border-radius values outside: 6px, 8px, 15px, 16px, 24px, 30px, 40px, 50%
