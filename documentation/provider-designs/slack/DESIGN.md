## 1. Visual Theme & Atmosphere

**Overall mood:** Dark and moody

**Density:** Moderate. The layout uses a varied spacing scale.

**Shape language:** Subtle rounding on interactive elements.

**Depth:** Uses 1 shadow style for layering and elevation.

## 2. Color Palette & Roles

- **White** (`#FFFFFF`) — Page background
- **Dark Pink** (`#4A154B`) — Dark background / footer
- **Black** (`#000000`) — Primary text
- **Dark gray** (`#616061`) — Secondary text
- **Dark Blue** (`#1264A3`) — Secondary text
- **Light gray** (`#DDDDDD`) — Divider / border
- **Dark gray** (`#5E5D6073`) — Divider / border

## 5. Layout Principles

**Spacing scale:** 4px, 8px, 12px, 16px, 20px, 24px, 32px, 40px

**Base unit:** 4px grid (values are mostly multiples of 4).

**Border radii:** 12px

## 6. Guidelines

### Do
- Use 4px grid for all spacing
- Use `#000000` for primary actions and CTAs
- Stick to 3 font weights: 400, 500, 700
- Use `Salesforce-Avant-Garde` as the primary typeface

### Don't
- Don't introduce colors outside the palette above
- Don't mix fonts beyond Salesforce-Avant-Garde and Slack-Lato
- Don't use inline styles when the design system covers the pattern
- Don't use border-radius values outside: 12px
