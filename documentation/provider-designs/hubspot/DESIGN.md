# Design System: HubSpot Login and Sign in

> Extracted from [https://app.hubspot.com/login](https://app.hubspot.com/login) by brandmd

## 1. Visual Theme & Atmosphere

**Overall mood:** Balanced and professional

**Density:** Compact. The layout uses a varied spacing scale.

**Shape language:** Sharp, geometric edges.

**Depth:** Flat design with minimal shadow usage.

## 2. Color Palette & Roles

- **White** (`#FFFFFF`) — Page background
- **Dark Muted Blue** (`#33475B`) — Primary text
- **Cyan** (`#0091AE`) — Secondary text
- **Muted Blue** (`#99ACC2`) — Muted text
- **Red** (`#FF7A59`) — Link / accent text
- **Light Muted Blue** (`#CBD6E2`) — Divider / border
- **Black** (`#14141400`) — Divider / border

## 3. Typography Rules

**Primary font:** Lexend Deca

**Fonts by role:**
- Headings: Lexend Deca
- Body: Lexend Deca

**Type scale:**
- Body / UI: 14px, 16px, 22px
- Captions / Small: 12px

**Weights in use:** 300, 400, 500, 600

**Line heights:** 24px, 14px, 18px, 27px

## 5. Layout Principles

**Spacing scale:** 2px, 4px, 8px, 10px, 12px, 16px, 24px, 32px

**Base unit:** 4px grid (values are mostly multiples of 4).

**Border radii:** 3px

## 6. Guidelines

### Do
- Use 4px grid for all spacing
- Use `#33475B` for primary actions and CTAs
- Stick to 4 font weights: 300, 400, 500, 600
- Use `Lexend Deca` as the primary typeface

### Don't
- Don't introduce colors outside the palette above
- Don't mix fonts. Use Lexend Deca everywhere
- Don't use inline styles when the design system covers the pattern
- Don't use border-radius values outside: 3px
