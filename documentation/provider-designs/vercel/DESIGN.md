# Design System: Login – Vercel

> Extracted from [https://vercel.com/login](https://vercel.com/login) by brandmd

## 1. Visual Theme & Atmosphere

**Overall mood:** Balanced and professional

**Density:** Compact. The layout uses a varied spacing scale.

**Shape language:** Subtle rounding on interactive elements.

**Depth:** Uses 3 shadow styles for layering and elevation.

## 2. Color Palette & Roles

- **White** (`#FFFFFF`) — Page background
- **Black** (`#171717`) — Dark background / footer
- **Dark Blue** (`#0072F5`) — Secondary text
- **Dark gray** (`#888888`) — Secondary text
- **Light gray** (`#EBEBEB`) — Divider / border
- **Black** (`#000000`) — Divider / border

## 3. Typography Rules

**Primary font:** Geist
**Secondary font:** geistMonoFont

**Fonts by role:**
- Headings: Geist
- Body: Geist

**Type scale:**
- Headings: 32px
- Body / UI: 14px, 16px
- Captions / Small: 12px

**Weights in use:** 400, 500, 600

**Line heights:** 24px, 20px, 16px, 40px

**Letter spacing:** -0.96px

## 4. Component Stylings

### Buttons
- Background: `rgb(255, 255, 255)`
- Text color: `rgb(23, 23, 23)`
- Corner radius: 6px
- Padding: 0px 6px 0px 6px
- Font: 14px, weight 500

### Cards
- Padding: 0px 0px 0px 0px

### Inputs
- Background: `rgb(255, 255, 255)`
- Border: 0px none rgb(0, 0, 0)
- Corner radius: 8px
- Padding: 0px 12px 0px 12px
- Font size: 16px

## 5. Layout Principles

**Spacing scale:** 2px, 6px, 8px, 12px, 14px, 16px, 24px, 32px

**Base unit:** 8px grid (values are mostly multiples of 8).

**Border radii:** 4px, 6px, 8px

## 6. Guidelines

### Do
- Use 8px grid for all spacing
- Stick to 3 font weights: 400, 500, 600
- Use `Geist` as the primary typeface

### Don't
- Don't introduce colors outside the palette above
- Don't mix fonts beyond Geist and geistMonoFont
- Don't use inline styles when the design system covers the pattern
- Don't use border-radius values outside: 4px, 6px, 8px
