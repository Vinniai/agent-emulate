## 6. Guidelines

### Do
- Use 4px grid for all spacing
- Use `#29ABE2` for primary actions and CTAs
- Stick to 2 font weights: 400, 500
- Use `Albert Sans Variable` as the primary typeface

### Don't
- Don't introduce colors outside the palette above
- Don't mix fonts beyond Albert Sans Variable and SFMono-Regular
- Don't use inline styles when the design system covers the pattern
- Don't use border-radius values outside: 2.298px, 2.783px, 3.226px, 4px, 6.452px, 8px, 50%, 3.35544e+07px
