# Design System: Manage your Apple Account

> Extracted from [https://appleid.apple.com/sign-in](https://appleid.apple.com/sign-in) by brandmd

## 1. Visual Theme & Atmosphere

**Overall mood:** Dark and moody

**Density:** Moderate. The layout uses a varied spacing scale.

**Depth:** Flat design with minimal shadow usage.

## 2. Color Palette & Roles

- **White** (`#FFFFFF`) — Page background
- **Black** (`#000000`) — Primary text
- **Dark gray** (`#6E6E73`) — Secondary text
- **Dark gray** (`#424245`) — Primary text
- **Dark Blue** (`#0066CC`) — Secondary text

## 3. Typography Rules

**Primary font:** SF Pro Text
**Secondary font:** SF Pro Display

**Fonts by role:**
- Headings: SF Pro Text
- Body: SF Pro Text

**Type scale:**
- Headings: 24px, 44px
- Body / UI: 17px, 21px
- Captions / Small: 12px

**Weights in use:** 400, 600

**Line heights:** 25px, 12px, 44px, 16.0004px, 22px, 21.0012px, 24px

**Letter spacing:** -0.374px, -0.12px, 0.231px, 0.216px

## 4. Component Stylings

### Buttons

### Cards

### Inputs

## 5. Layout Principles

**Spacing scale:** 2px, 3px, 5px, 7px, 8px, 10px, 22px, 24px

**Base unit:** 8px grid (values are mostly multiples of 8).

## 6. Guidelines

### Do
- Use 8px grid for all spacing
- Use `#000000` for primary actions and CTAs
- Stick to 2 font weights: 400, 600
- Use `SF Pro Text` as the primary typeface

### Don't
- Don't introduce colors outside the palette above
- Don't mix fonts beyond SF Pro Text and SF Pro Display
- Don't use inline styles when the design system covers the pattern
